# SQL Sales Analysis using Superstore Dataset

## Project Overview

This project is about using SQL to look at sales data and get some ideas from a dataset. I used the Superstore dataset and MySQL to do this. I looked at the data filtered it added things up and checked for trends. I also made sure the data was good.

## Objective

The main goal of this project is to use SQL to look at sales data and answer business questions.

* Looking at the dataset to see what it has

* Filtering the data to get what I need

* Adding things up to get totals

* Finding the products and customers

* Looking at sales over time
